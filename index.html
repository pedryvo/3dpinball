Manual de Controles

Flippers: Left Shift / Right Shift ou Z / /

Lançador (Plunger): Segure e solte a Barra de Espaço ou Seta para Baixo

Empurrão (Nudge / Tilt): X / S / C ou Setas Esquerda / Cima / Direita

Pausa & Novo Jogo: P para Pausar, F2 para Novo Jogo, 1-3 para Trocar Mesa

Controle (Gamepad): Gatilhos L1/R1 ou L2/R2 para Flippers, Botão A para Lançador, D-Pad/Analógico para Empurrão (Nudge) com vibração háptica nos impactos.

Dispositivos Móveis: Toque nos botões na parte inferior da tela para rebatedores e mola.
