## 🚀 О проекте

**3dpinball** исследует оригинальный исполняемый файл _3-D Ultra Pinball_ (`PINBALL.EXE`), аудиосистему (`SOS9502.DLL`) и архивы ресурсов (`RESOURCE.MAP`, `RESOURCE.001`, `RESOURCE.002`) (Dynamix / Sierra On-Line, 1995) с помощью **REA** (Reverse Engineer Anything) и Ghidra для реконструкции форматов данных, оконных процедур (`@mainWndProc$qpvuiuil`, `@pinWndProc$qpvuiuil`), 2D/Z-буфер рендерера Three-Space (`TS_DRAW.C`, `GFXDevWinG`) и физики столкновений и сплайнов (`PB_COL.C`, `PB_SPLIN.C`, `PB_FRAME.C`).

В отличие от тяжеловесных эмуляторов x86, этот порт работает нативно на TypeScript, WebAssembly и HTML5 Canvas **без накладных расходов эмуляции**:

- 🌐 **Современный Sci-Fi HUD космической базы и интерфейс Windows 95**: Аутентичное окно в стиле Windows 95 в сочетании с тактической панелью космической колонии (светодиодное табло счета, телеметрия множителей, миссии на 3 столах: **Колония**, **Командный пост** и **Шахта**, а также доступные HTML5-меню).
- 📱 **Адаптация для мобильных устройств (Touch-Ready)**: Отзывчивый интерфейс для смартфонов и планшетов с экранными кнопками левого и правого флипперов, плунжером запуска шара и кнопками толчка стола (Nudge/Tilt).
- 🎨 **Пиксель-перфектная 256-цветная графика и Z-буфер**: Декодирование палитр (`.PAL`), битмапов (`.BMP`), анимаций (`.ANM`) и интерфейсов (`.ITF`) Dynamix через 8-битный конвейер (`GFXPalette`, `GFXZBuffer`).
- ⚙️ **Ядро физики и сплайнов на WebAssembly**: Высокочастотная симуляция шара с подшагами, угловой импульс флипперов, упругость бамперов, сплайны рамп (`PB_SPLIN.C`) и маски столкновений (`PB_COL.C`).
- 🔊 **Звук и синтезатор через Web Audio API**: Прямое воспроизведение оригинальных PCM `.WAV` эффектов (`SX_%04d.WAV`) и синтезированной FM/MIDI музыки (`SX_%04d.MID`).
- 🌍 **Полная локализация на 6 языков (i18n)**: Автоматический выбор языка пользователя (**Бразильский португальский**, **Английский**, **Испанский**, **Русский**, **Упрощенный китайский** и **Немецкий**) с мгновенным переключением на лету.
- ⚡ **Готовность к деплою на Vercel**: Сверхбыстрая сборка Vite для статического хостинга на Vercel.

## 📊 Прогресс

| Раздел | Статус | Подробности |
|---|:---:|---|
| **План и архитектура** | ✅ | Полный роадмап проекта · [`docs/PLAN.md`](docs/PLAN.md) |
| **Реверс-инжиниринг (REA)** | ✅ | PE-анализ `PINBALL.EXE` и распаковка инсталлятора Clickteam · [`re/binary_analysis.json`](re/binary_analysis.json) |
| **Парсер `RESOURCE.MAP` / Ресурсов** | ✅ | Бинарный парсер для `.BMP`, `.PAL`, `.ANM`, `.ITF`, `.WAV`, `.MID`, `.RES` · [спецификация](docs/formats/resource_map.md) |
| **256-цветный рендерер и Z-буфер** | ✅ | 8-битное поле, анимированные бамперы, флипперы, рампы и LED-табло |
| **Физическое ядро WebAssembly** | ✅ | Высокоточная 480Гц симуляция (`PB_COL`), кривые Безье (`PB_SPLIN`) и тилт |
| **Аудиодвижок** | ✅ | Web Audio API для звуковых эффектов с панорамированием и FM-синтезатор · [спецификация](docs/formats/sound.md) |
| **3 Игровых Стола** | ✅ | **Колония**, **Командный пост** и **Шахта**, система миссий и мультибол |
| **HTML5 Интерфейс** | ✅ | Окно Windows 95, выпадающие меню, настройки и таблица рекордов |
| **Сенсорное управление и геймпады** | ✅ | Экранные кнопки для мобильных и виброотдача для контроллеров |
| **Локализация (i18n)** | ✅ | Полная поддержка 6 языков: PT-BR, EN, ES, RU, ZH-CN, DE |
| **Автоматические регрессионные тесты** | ✅ | 10 полных наборов тестов (`npm test`) |
| **PWA и деплой на Vercel** | ✅ | Service Worker для оффлайн-игры и оптимизированная сборка (`vercel.json`) |

## 🎮 Запуск игры

```bash
git clone https://github.com/pedryvo/3dpinball.git
cd 3dpinball
npm install
npm run dev
```

Откройте `http://localhost:3000` в браузере, чтобы начать игру!

## 🕹️ Управление

| Действие | Клавиатура (ПК) | Сенсорный экран (Смартфон) |
|---|---|---|
| **Левый флиппер** | `Левый Shift` / `Z` / `Стрелка влево` | ◀ Зона **ЛЕВЫЙ ФЛИППЕР** |
| **Правый флиппер** | `Правый Shift` / `/` / `Стрелка вправо` | Зона **ПРАВЫЙ ФЛИППЕР** ▶ |
| **Запуск шара (Плунжер)** | `Пробел` / `Enter` / `Стрелка вниз` | 🚀 Удерживать и отпустить **ПУСК** |
| **Толчок стола влево** | `X` или `A` | ↖ Кнопка **ТОЛЧОК ЛЕВ** |
| **Толчок стола вправо** | `.` или `D` | ↗ Кнопка **ТОЛЧОК ПРАВ** |
| **Толчок стола вверх** | `Стрелка вверх` или `W` | ▲ Кнопка **ТОЛЧОК ВВЕРХ** |
| **Смена стола (Колония / Пост / Шахта)** | `1`, `2`, `3` | 🎯 Выбор стола |
| **Пауза** | `P` / `Esc` | ⏸️ Кнопка паузы |
| **Новая игра** | `F2` | 🎮 Меню «Новая игра» |
